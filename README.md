# Домашнее задание к занятию "`Репликация и масштабирование. Часть 2`" - `Шалыгин Денис`

### Задание 1

Опишите основные преимущества использования масштабирования методами:

активный master-сервер и пассивный репликационный slave-сервер;
master-сервер и несколько slave-серверов;
Дайте ответ в свободной форме.

### Ответ

1 Активный master-сервер и пассивный репликационный slave-сервер

Преимущества

Повышение отказоустойчивости. При падении Master-сервера Slave можно оперативно перевести в режим Master.
Резервное копирование. Резервные копии можно создавать с Slave-сервера, не нагружая Master и не влияя на работу пользователей.

2. Master-сервер и несколько slave-серверов

Преимущества

Масштабирование нагрузки на чтение. Запросы на чтение, которые обычно составляют большинство в веб-приложениях распределяются между несколькими Slave-серверами.
Геораспределение. Slave-серверы можно размещать в разных географических регионах, чтобы уменьшить задержку для конечных пользователей.
Повышенная отказоустойчивость. При выходе из строя одного из Slave-серверов, нагрузка на чтение перераспределяется между оставшимися.

Режимы работы серверов

Master-сервер в каждом шарде для обработки всех операций записи для данных, принадлежащих этому шарду. Принимает данные репликации от мастера вышестоящего уровня.

Slave-серверы в каждом шарде для 
Масштабирование чтения обслуживание запросов SELECT для приложения.
Резервирование Готовы заменить Master в случае его отказа.

Режим горячего резерва в режиме репликации "только чтение". Данные постоянно синхронизируются с Master-сервером своего шарда.
